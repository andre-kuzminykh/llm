# CP — Контент-план: спецификация

Отдел SMM в Neuronium; его первая часть — управление контент-планом Andre AIT без таблиц: календарь
(неделя или месяц), черновики (банк идей) и рубрики; дашборда нет. Сетка правил и проверка работают внутри — отдельных
экранов у них нет. Данные: план Датаиста — расписание из таблицы владельца (`../source/schedule.csv` → `npm run seed` → `public/seed.json`, FR-CP-075): каналы × категории × рубрики × время, контента нет — слоты «Нужна тема»; дальше правки живут в браузере; прежний пример из `../build.py` — фикстура тестов `src/test/seed-andre.json`.
Порядок работы как в Neuronium: история → сценарий → требование → тест → код. Визуальный язык — дизайн-система
Neuronium (A39 `WUI`): Montserrat, один фиолетовый акцент, светлая и тёмная тема; левая панель — отделы, как F20 `EMP`.

## 1. Термины

| Термин | Значение |
|---|---|
| Канал | Neuronium, Лаборатория Датаиста, Академия Датаиста, Офис Датаиста, Andre AIT, Landao, Antropolis. Датаист — три отдельных канала (в исходной таблице — Dataist с разделами Лаборатория, Академия, Кабинет): исследования — в Лаборатории, Академия — в Академии, остальное — в Офисе. Три канала Датаиста по умолчанию серые; цвет любого канала меняется в фильтрах. Разделы у канала возможны, но в плане их нет |
| Площадка | Web, YouTube, Instagram, TikTok, Threads, X, Telegram, LinkedIn, Mail |
| Рубрика | О чём материал — она же тема в программе: Демо, Технологии, Академия, Тезисы…; везде — просто названием, без «#» (набранное «#кейсы_клиентов» станет «Кейсы клиентов»). Отдельной «общей темы» над материалами нет |
| Формат | Какой это материал по виду. Видео: полное горизонтальное видео, короткое вертикальное видео. Текст: страница на сайте, текст с картинкой |
| Формат рубрики (правило) | Как рубрика выходит: FULL, тизер, анонс, урок, письмо — у каждого свой формат из четырёх. Правило: канал, площадки, что выходит на каждой площадке, дни недели, время, лимит в день. Общие форматы (тизер, анонсы, кросс-посты) выходят с FULL рубрики и берут её рубрику |
| Тип контента | Что выходит на площадке в этом формате: YouTube — FULL или Shorts, Instagram — Reels, Web — статья, Mail — письмо |
| Материал | Одна публикация: дата и время, канал, раздел, рубрика, формат, тема, площадки, статус, заметка |
| Тема | Название материала — только тема («Стратегия»): рубрика стоит меткой рядом, формат — в типах под площадками |
| Карточка | Материал целиком в одном канале: FULL с тизером, анонсом в Офисе и в X — одна карточка Офиса Датаиста; анонс Andre AIT и кросс-посты — свои карточки. Залита цветом канала, полоска слева — им же |
| Группа | Материалы, которые двигаются вместе: FULL и его тизер, анонсы, письма; Разбор и Призыв |
| Производный материал | Член группы, у которого тема — от главного (`{title}`) |
| Слот | Материал без темы — «…», на карточке «Нужна тема» |
| Банк тем | Темы без даты для форматов с банком (Демо · FULL, Тезисы · Тезис дня…); раскладываются по слотам |
| Задача | Что сделать по карточке: часть на каждую площадку с галочкой, дата и время выхода, статус, заметка. Открывается по ▶ |
| Срок подготовки | Когда материал должен быть готов: FULL — за 3 дня до выхода, остальное — за день, авто-рубрики — в день выхода; в форме и задаче не правится (раньше — для «Что делать» в дашборде, его больше нет) |
| Вне сетки | Разовый материал, который проверка не трогает: новый на день, когда рубрика по сетке не выходит, или с новым форматом — сам, переключателя нет; так же тизеры и анонсы, уехавшие со своей карточкой на «чужой» для них день при «Наверстать» |

## 4. Сценарии системы (Gherkin)

```gherkin
# UC-CP-1 — неделя
Given план загружен
When я открываю календарь на неделе 9–15 ноября 2026
Then в каждом дне видны все единицы контента: время, рубрика, тема
And пустой слот — пунктирной строкой «Нужна тема»
And фильтр по каналу, площадке, рубрике или статусу убирает лишние строки

# UC-CP-2 — перенос с группой
Given FULL «Демо: Стратегия» 26.10 с тизером, анонсом в Кабинете, X и Andre AIT
When я переношу FULL на 27.10
Then все пять материалов группы стоят на 27.10
And если выключено «двигать группу», переезжает только FULL

# UC-CP-3 — перенос на день, где рубрика не выходит
Given Тезис стоит в понедельник
When я переношу его на субботу
```

Состояние — один `useReducer`; история для отмены — снимки состояния (структурное разделение,
копируются только изменённые материалы). Сохранение — с задержкой 400 мс после правки.

Neuronium (nr-launch/1). Одна переменная — два места, которые обязаны говорить одно:

```
NR_HOST_ORIGINS      ┌─ npm run build ──────────────────────→ dist/nr-launch.json: "frame": true | false
(окружение или .env) ┤                                          (Neuronium читает его со своего сервера)
                     └─ node scripts/nr-launch.mjs nginx|caddy → frame-ancestors 'self' <адреса>
                                                                (браузер пускает во фрейм только их)
```

Neuronium открывает SMM во фрейме, только если паспорт не просит вкладку и заголовки ответа его пускают; иначе —
новая вкладка. Сервера приложения у SMM нет, поэтому заголовки ставит nginx или Caddy (`deploy/README.md`).

Меню отделов одно — у Neuronium (FR-CP-069, FR-CP-070). Во фрейме SMM рисует только своё:

```
inFrame() = window.top !== window.self   (один раз при открытии; top недоступен — тоже фрейм)
  нет  → [Nr · десять отделов · Профиль] [Главная · Календарь] [Фильтры] [главная или календарь]
  да   → [Главная · Календарь · … · Настройки] [Фильтры] [главная или календарь]   (слева — рейл Neuronium)
телефон, нет → внизу: Главная · Календарь · Профиль
телефон, да  → вверху, строкой над шапкой страницы: Главная · Календарь · Настройки (то же меню, шестерёнка вместо кружка,
               раскрывается под строкой); внизу у SMM ничего — нижняя панель одна, у Neuronium
```
