# CP — Контент-план: спецификация

Отдел SMM в Neuronium; его первая часть — управление контент-планом Andre AIT без таблиц: дашборд
(что делать, банк идей, темы-хэштеги) и календарь. Сетка правил и проверка работают внутри — отдельных
экранов у них нет. Данные: план из `../build.py` (`public/seed.json`), дальше правки живут в браузере.
Порядок работы как в Neuronium: история → сценарий → требование → тест → код. Визуальный язык — дизайн-система
Neuronium (A39 `WUI`): Montserrat, один фиолетовый акцент, светлая и тёмная тема; левая панель — отделы, как F20 `EMP`.

## 1. Термины

| Термин | Значение |
|---|---|
| Канал | Neuronium, Лаборатория Датаиста, Академия Датаиста, Офис Датаиста, Andre AIT, Landao, Antropolis. Датаист — три отдельных канала (в исходной таблице — Dataist с разделами Лаборатория, Академия, Кабинет): исследования — в Лаборатории, Академия — в Академии, остальное — в Офисе. Три канала Датаиста по умолчанию серые; цвет любого канала меняется в фильтрах. Разделы у канала возможны, но в плане их нет |
| Площадка | Web, YouTube, Instagram, TikTok, Threads, X, Telegram, LinkedIn, Mail |
| Рубрика | О чём материал: Демо, Технологии, Академия, Тезисы… |
| Формат | Какой это материал по виду. Видео: полное горизонтальное видео, короткое вертикальное видео. Текст: страница на сайте, текст с картинкой |
| Формат хэштега (правило) | Как рубрика выходит: FULL, тизер, анонс, урок, письмо — у каждого свой формат из четырёх. Правило: канал, площадки, что выходит на каждой площадке, дни недели, время, лимит в день. Общие форматы (тизер, анонсы, кросс-посты) выходят с FULL рубрики и берут её рубрику |
| Тип контента | Что выходит на площадке в этом формате: YouTube — FULL или Shorts, Instagram — Reels, Web — статья, Mail — письмо |
| Материал | Одна публикация: дата и время, канал, раздел, рубрика, формат, тема, площадки, статус, кто делает, срок подготовки |
| Тема | Название материала — только тема («Стратегия»): рубрика стоит меткой рядом, формат — в типах под площадками |
| Карточка | Материал целиком в одном канале: FULL с тизером, анонсом в Офисе и в X — одна карточка Офиса Датаиста; анонс Andre AIT и кросс-посты — свои карточки. Залита цветом канала, полоска слева — им же |
| Программа | Дашборд, перевёрнутый в программу — что выпускаем: по хэштегам (каналы → хэштеги → что и когда выходит) или по общим темам; время — подписью, не шкалой |
| Общая тема | Одна тема над несколькими материалами разных форматов и каналов: «ИИ-агенты в продажах» — полное видео, шортс, страница на сайте. Не путать с темой материала (его названием) и хэштегом |
| Группа | Материалы, которые двигаются вместе: FULL и его тизер, анонсы, письма; Разбор и Призыв |
| Производный материал | Член группы, у которого тема — от главного (`{title}`) |
| Слот | Материал без темы — «…», на карточке «Нужна тема» |
| Банк тем | Темы без даты для форматов с банком (Демо · FULL, Тезисы · Тезис дня…); раскладываются по слотам |
| Задача | Что сделать по карточке: часть на каждую площадку с галочкой, срок подготовки, кто делает, заметка. Открывается по ▶ |
| Срок подготовки | Когда материал должен быть готов: FULL — за 3 дня до выхода, остальное — за день, авто-рубрики — в день выхода; у материала можно задать свой |
| Вне сетки | Разовый материал, который проверка не трогает |

## 8. Архитектура

```
public/seed.json  ← ../build.py (правила → план)
src/model/        чистая логика, без React
  types.ts        Канал, Рубрика, Формат (правило), Материал, тип контента на площадке, время
  dates.ts        ISO-даты, дни недели (Пн = 0), время «ЧЧ:ММ»
  planning.ts     планирование недели: слоты без темы до конца следующей недели
  calendar.ts     календарь из nr_management: дни окна, блоки и колонки пересечений, 15 минут, растягивание, лист, лента дней, конец жеста
  units.ts        карточки дня (материал целиком в канале), типы по площадкам, срок подготовки, части задачи
  store.ts        reducer: move (дата и время) · update · updateMany (и триггер версий) · create · duplicate (на дату) · versions · batch · remove · bank · fillSlots · unassign · rubric · channel · undo/redo
  rules.ts        проверка правил (одно событие — одно нарушение, вне сетки), типовая неделя
  filters.ts      фильтры и индекс по датам
  io.ts           JSON и CSV-календарь, перевод первой и второй версии
  storage.ts      IndexedDB, с запасным вариантом в памяти
src/ui/           атомы в стиле Neuronium: иконки (и площадок), карточка, статусы, галочки; infinite.ts — бесконечная лента дат; drag.ts — перенос карточек указателем
src/views/        Неделя (время / дорожки) · Лента (телефон) · Дашборд (панель справа: уточнить темы, что делать, темы и периодичность) ·
                  Планирование недели · Черновики (вкладка «+») · День · Задача · Форма · Как пользоваться
src/App.tsx       панель отделов Neuronium + фильтры (сворачиваются) + календарь + листы справа + «+»
```

Состояние — один `useReducer`; история для отмены — снимки состояния (структурное разделение,
копируются только изменённые материалы). Сохранение — с задержкой 400 мс после правки.
