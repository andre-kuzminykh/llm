# CP — Контент-план: спецификация

Приложение для управления контент-планом Andre AIT без таблиц: календарь, сетка рубрик,
банк тем и проверка правил. Данные: план из `../build.py` (`public/seed.json`), дальше
правки живут в браузере. Порядок работы как в Neuronium: история → сценарий → требование
→ тест → код. Визуальный язык — дизайн-система Neuronium (A39 `WUI`): Montserrat, фиолетовый
акцент, оранжевый второй, светлая и тёмная тема.

---

## 1. Термины

| Термин | Значение |
|---|---|
| Канал | Бренд: Neuronium, Dataist, Andre AIT, Landao, Antropolis. У Dataist есть разделы (Lab, Academy, Office) |
| Площадка | Web, YouTube, Instagram, TikTok, Threads, X, Telegram, LinkedIn, Mail |
| Рубрика | Тип материала с правилами: канал, площадки, дни недели, лимит в день, шаблон заголовка |
| Материал | Одна публикация: дата, канал, раздел, рубрика, заголовок, площадки, статус |
| Группа | Материалы, которые двигаются вместе: FULL и его тизер, анонсы, письма; Разбор и Призыв |
| Производный материал | Член группы, чей заголовок собирается из главного по шаблону (`Тизер: {title}`) |
| Слот | Материал без темы — в заголовке «…» |
| Банк тем | Темы рубрики без даты; раскладываются по слотам |

## 4. Сценарии системы (Gherkin)

```gherkin
# UC-CP-1 — месяц
Given план загружен
When я открываю месяц ноябрь 2026
Then в каждом дне виден FULL дня, счётчики по каналам, число слотов без темы
And суббота подписана «отдых»

# UC-CP-2 — перенос с группой
Given FULL «Демо / Стратегия» 26.10 с тизером, анонсом в Кабинете, X и Andre AIT
When я переношу FULL на 27.10
Then все пять материалов группы стоят на 27.10
And если выключено «двигать группу», переезжает только FULL

# UC-CP-3 — перенос на день, где рубрика не выходит
Given Тезис стоит в понедельник
When я переношу его на субботу
Then он переезжает, а в субботе появляется нарушение «рубрика не выходит в этот день»

# UC-CP-4 — правка главного материала
Given FULL «Демо / …» с производными «Тизер: {title}» и «Анонс / {topic}»
When я меняю заголовок на «Демо / Агент продаж»
Then тизер становится «Тизер: Демо / Агент продаж», анонс — «Анонс / Агент продаж»

# UC-CP-5 — банк тем
Given в банке рубрики «FULL: Демо» две темы и впереди есть слоты «Демо / …»
When я нажимаю «Разложить по слотам»
Then темы встают в ближайшие слоты по порядку, производные обновляются, банк пустеет

# UC-CP-6 — тема без слота
Given в банке «Тезис дня» тем больше, чем слотов
When я раскладываю
Then разложены темы по числу слотов, остальные остались в банке, и я вижу, сколько не влезло

# UC-CP-7 — новый материал по образцу
Given в рубрике «FULL: Демо» есть материал с группой
When я создаю FULL: Демо на свободный понедельник с флажком «с сопутствующими»
Then создаются FULL и копии его группы со слотом «…» на новую дату

# UC-CP-8 — сетка
When я выключаю понедельник у «FULL: Демо»
Then все Демо по понедельникам помечены нарушением, а типовая неделя убирает Демо из понедельника

# UC-CP-9 — сохранение
Given я перенёс материал
When я перезагружаю страницу
Then материал на новой дате
And если хранилище недоступно, приложение работает и предупреждает, что правки не сохранятся

# UC-CP-10 — отмена
Given я удалил материал
When я нажимаю ⌘Z
Then материал вернулся

# UC-CP-11 — импорт
When я загружаю JSON, выгруженный этим приложением
Then план заменён им
And если файл не тот, план не меняется и я вижу ошибку

# UC-CP-12 — канал не запущен
Given Landao стартует 02.11.2026
When материал Landao стоит раньше
Then это нарушение «канал ещё не запущен»
```

## 8. Архитектура

```
public/seed.json  ← ../build.py (правила → план)
src/model/        чистая логика, без React
  types.ts        Канал, Рубрика, Материал, Состояние
  dates.ts        ISO-даты, дни недели (Пн = 0), сетка месяца
  store.ts        reducer: move · update · create · duplicate · remove · bank · fillSlots · rubric · channel · undo/redo
  rules.ts        проверка правил, типовая неделя
  filters.ts      фильтры и индекс по датам
  io.ts           JSON и CSV-календарь
  storage.ts      IndexedDB, с запасным вариантом в памяти
src/ui/           атомы в стиле Neuronium: иконки, кнопки, чипы
src/views/        Месяц · Неделя · День · Форма · План · Банк тем · Сетка · Проверка
src/App.tsx       рейл + боковая панель + основная область
```

Состояние — один `useReducer`; история для отмены — снимки состояния (структурное разделение,
копируются только изменённые материалы). Сохранение — с задержкой 400 мс после правки.
