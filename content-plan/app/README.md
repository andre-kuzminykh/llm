# SMM · контент-план — приложение

Отдел **SMM** в Neuronium, и его первая часть — управление контент-планом: календарь вместо таблиц, дашборд панелью справа,
черновики (банк идей) и рубрики с периодичностью по каналам. Слева, как в Neuronium, — панель отделов: Менеджмент, HR,
Маркетинг, SMM, Продажи, Поддержка, Аналитика, Дизайн, Разработка, Инжиниринг (открыт SMM, остальные — «скоро»),
сверху знак Nr, снизу профиль; рядом — фильтры (сворачиваются).
Стиль — дизайн-система Neuronium (Montserrat, один фиолетовый акцент, светлая и тёмная тема). Спецификация — [`SPEC.md`](SPEC.md).

## Запуск

```bash
cd content-plan/app
npm install
npm run dev        # http://localhost:5174
```

Собрать статический сайт (кладётся куда угодно: nginx, GitHub Pages, любой хостинг):

```bash
npm run build      # → dist/
npm run preview    # посмотреть сборку на http://localhost:5174
```

## Что умеет

| Экран | Что там |
|---|---|
| **Календарь** | Главный экран. В правом углу шапки — **«Неделя / Месяц»** значками, выбран один (рядом, левее, — значок дашборда). **Неделя** листается вбок без конца; вид — справа, с иконками: «Время» (по умолчанию) — шкала часов из календаря nr_management: с первого материала недели; карточка без конца — полчаса; совпадающие по времени — рядом, все видны; лента Neuronium «24/7» — строкой над часами; карточку берут и ставят на другой день и час (по 15 минутам), тянут за нижний край, пустой лист тянут рукой; **щелчок по пустому месту шкалы — новый контент на этот день и получас**. «Каналы», «Площадки», «Темы» — дорожками (сворачиваются); в «Каналах» каналы правятся прямо в дорожках: «⋯» — переименовать, выше, ниже, удалить, внизу «Добавить канал». **Месяц** — недели строками, в каждом дне все карточки (ничего не прячется), перенос на другой день, щелчок по пустому месту дня — новый контент; стрелки — соседний месяц. Где тесно — меню «Вид», на телефоне в нём ещё «Лента по дням». Нажать на день — панель со всеми материалами дня |
| **Фильтры слева** | Сворачиваются и разворачиваются кнопкой «Фильтры» слева от даты (большой экран помнит как; на узком — поверх календаря); свёрнутые — метками в шапке и числом на кнопке. Каналы: Neuronium, Лаборатория Датаиста, Академия Датаиста, Офис Датаиста (три серых, отдельно), Andre AIT, Landao, Antropolis — порядок меняется перетаскиванием строки; точка у канала — палитра; «⋯» у канала — переименовать (прямо в строке), выше, ниже, удалить (с подтверждением, вместе с его форматами и материалами; ⌘Z возвращает); площадки с иконками; форматы — «Видео» и «Текст»; **рубрики — щелчок выделяет, видны только выделенные (ничего не выделено — все), «Выделить все» / «Снять выделение»**; статус, «Ежедневные авто-публикации», «Только без темы»; «+» у каналов, площадок и рубрик — добавить новое |
| **Дашборд** — значок справа вверху | Открывается панелью справа, календарь под ним. Вверху — «Сводка | Программа». **Программа** — что выпускаем: каналы, в них рубрики (рубрика и есть тема — отдельной «общей темы» нет), по каждой — темы материалов, справа дата и время («21 окт 10:00») и площадки значками; одно и то же каждый день — одной строкой. Период — неделя, месяц или все (у рубрики сначала 10 строк, дальше «Показать ещё»); строка открывает материал. **Сводка**: за неделю — «уточните темы»: «Уточнить» — все слоты без темы до конца следующей недели, тему вписать или взять ближайший черновик той же рубрики. **Не вышло вовремя** (дата прошла, «Вышло» не отмечено) → **«Наверстать» — одной кнопкой**: просроченное встаёт на ближайшие места сетки своего формата, а стоявшее там сдвигается по очереди дальше — до первого пустого слота (его занимают, дальше всё на месте) или до конца; тизеры и анонсы едут со своей карточкой; «Отменить» в тосте или ⌘Z возвращает всё; дальше можно переставлять руками. **Перенести период (отпуск)**: даты, каналы и куда — «На следующие слоты» (очередь сдвигается, в периоде пусто) или «В свободные места» (только материалы периода); авто-публикации и потоки 24/7 идут сами. Сводка — просрочено, в работе, готово; «Что делать» — на две недели вперёд: сверху «Просрочено», дальше по дням выхода, ▶ — начать задачу, фильтр статуса словами. «Темы» — рубрики каждого канала: нажать — календарь только по ней; «Править» — переименовать, добавить рубрику в канал (с подсказками), задать периодичность: дни недели и время — слоты без темы встают в расписание |
| **«+» справа внизу** | Две вкладки: «Новый контент» и «Черновики» (банк идей). Новый контент — всё сразу, без «Подробнее»: сверху **рубрика** (подсказывается при вводе, как Т9; новая заведётся сама), под ней **тема**, дата и время, формат — значками, щёлкнуть один: «Горизонталь» (полное горизонтальное видео), «Вертикаль» (короткое вертикальное), «Веб» (страница на сайте), «Пост» (текст с картинкой), канал, площадки, статус, заметка, «С сопутствующими публикациями». Новый на «чужой» день — вне сетки сам, переключателя нет. «В черновики» — без даты. Черновики — по рубрикам: добавить списком, разложить по слотам, в ближайший слот, вернуть, перетащить на день |

Карточка — тихая строка без рамки: сверху #рубрика и формат, время, ниже тема («Стратегия»);
в панели дня и в задаче — ещё и площадки строкой: «YouTube — FULL, Тизер · Shorts · Web — Анонс · Офис».
Одна карточка — материал целиком в своём канале: FULL с тизером и анонсами — одна карточка Офиса Датаиста, анонс от Andre AIT
и кросс-посты — свои карточки. Карточка залита цветом канала, полоска слева — он же: на белом видно.

Как двигать и менять:
- **▶** на карточке или в «Что делать» — статус «в работе» и задача по созданию контента: что сделать на каждой
  площадке (с галочками), когда выход и перенос на другую дату, заметка.
- **Задача** — тема заголовком, под ней чек-лист по площадкам, ниже строкой «Пн, 26 окт · 12:00» (нажать — поменять), статус и «+ Заметка».
- **Статус** — значком: без значка — в плане, ▶ в работе, ⏸ на паузе, ✓ готово, ● вышло. На карточке — один значок в углу; все статусы — в задаче и в форме. Нажать тот же значок ещё раз — снова в плане.
- **Перенести** карточку — взять и вести (мышью сразу, пальцем — подержать): она едет за указателем, день под ней подсвечен,
  в неделе «Время» она встаёт по 15 минутам и на ней видно время, куда встанет; отпустить — готово, Esc — отмена.
  Так в неделе (по часам и дорожками), месяце, ленте и из панели дня. Нижний край карточки на шкале — длительность.
  Рядом с указателем — подсказка словами: куда встанет, что едет вместе и что отметит проверка на новом месте
  («Здесь уже FULL… — можно поменять местами», «по сетке не выходит в Сб», «сверх лимита в день»).
  FULL едет вместе со своей группой (тизер, анонс в Офисе, X, письма, Andre AIT); отключить можно в форме материала.
  Если на том дне уже есть FULL — в сообщении кнопка «Поменять местами».
- **Несколько карточек** — Shift- или ⌘-щелчок (пальцем — подержать и отпустить) выбирает; внизу «Выбрано: N»: статус всем,
  «Перенести на дату…» (промежутки сохраняются), удалить, ✕. Ведёте одну выбранную — едут все на тот же сдвиг дней и времени;
  отмена — одним шагом. Esc снимает выделение.
- **Перейти к дате** — нажать на заголовок календаря («9–15 ноя 2026») и выбрать дату. Материал можно поставить и после конца плана — план продлится.
- **Тема** — только тема, без рубрики: «Стратегия», а не «Демо / Стратегия». У тизера, анонсов и писем группы тема та же, что у FULL.
- **Черновик** — перетащить из вкладки «Черновики» на день: он займёт пустой слот этой рубрики или станет новым материалом.
- **Поиск** — вверху: от двух букв под полем найденное по датам и черновики; нажать — календарь на дате и материал открыт.
- **Форма материала** — всё сразу: рубрика, тема, дата и время, формат, канал, площадки, статус, заметка; у карточки с группой — «Переносить и удалять вместе с группой».
- **Новый контент** («+» справа внизу, «+» в дорожке недели, щелчок по пустому месту шкалы времени или дня месяца) по умолчанию
  создаётся с сопутствующими публикациями — по образцу ближайшего материала той же рубрики. Разовый материал на «чужой» день сразу «вне сетки».
- **⌘Z / Ctrl+Z** — отменить, **⇧⌘Z / Ctrl+Y** — повторить (до 100 шагов). После каждого действия — кнопка «Отменить» во всплывашке.
- **Фильтры** — в панели слева; кнопка «Фильтры» её сворачивает и разворачивает. Свёрнутые — метками в шапке, ✕ снимает.
- **Профиль** — внизу слева: «Как пользоваться» (все подсказки в одном месте), выгрузка и загрузка, тема оформления.
- **Телефон** — внизу Дашборд, Календарь и Профиль; «+» — справа внизу; фильтры — за кнопкой «Фильтры», вид — в меню «Вид», поиск — значком.

## Где хранится

План хранится **в браузере** (IndexedDB): правки переживают перезагрузку, но живут только в этом браузере.
Меню профиля внизу слева:
- **Выгрузить JSON** — весь план с правками, чтобы перенести на другой компьютер или сохранить копию;
- **Загрузить JSON** — открыть такую выгрузку (проверяется формат, чужой файл план не испортит);
- **Календарь для таблицы (CSV)** — тот же формат, что `../out/4_calendar.csv` (можно открыть в Google Sheets);
- **Сбросить к исходному плану** — заново взять `public/seed.json` (отменяется кнопкой «Отменить»);
- **Тема** — светлая, тёмная или как в системе.

Исходный план `public/seed.json` пишет генератор: `python3 ../build.py`. Если генератор
перезапущен, а в браузере уже есть правки, новый план подхватится только через «Сбросить к исходному плану».

## Тесты

```bash
npm test             # логика и интерфейс (vitest + Testing Library)
npm run typecheck
npm run build && npm run preview &   # затем:
npm run test:e2e     # настоящий браузер: перенос указателем, край, лист, месяц, щелчок по шкале, наверстать, рубрики, черновики, поиск, тёмная тема, телефон
```

`test:e2e` ищет Chromium в `/opt/pw-browsers`; другой путь — через переменную `CHROME`.
