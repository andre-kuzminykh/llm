# Контент-план — приложение

Календарь контент-плана вместо таблиц: смотреть, двигать, создавать и править материалы,
вести банк тем и сетку рубрик и форматов. Стиль — дизайн-система Neuronium (Montserrat, фиолетовый и
оранжевый акценты, светлая и тёмная тема). Спецификация — [`SPEC.md`](SPEC.md).

## Запуск

```bash
cd content-plan/app
npm install
npm run dev        # http://localhost:5174
```

Собрать статический сайт (кладётся куда угодно: nginx, GitHub Pages, любой хостинг):

```bash
npm run build      # → dist/
npm run preview    # посмотреть сборку на http://localhost:5174
```

## Что умеет

| Раздел | Что там |
|---|---|
| **Сейчас** | Что подготовить на две недели вперёд: сверху «Просрочено», дальше по дням выхода. В строке — время, рубрика, тема и срок подготовки (красным, если прошёл). ▶ — начать и открыть задачу; фильтр статуса словами |
| **Календарь** | Месяц листается неделями вверх и вниз без конца: в дне FULL (рубрика словом и тема), «ещё N» и «· 2 без темы» с подсказкой, каким рубрикам; пустой FULL — пунктиром; красная точка — нарушение. Нажать на день — панель со всеми материалами дня. На телефоне — лента по дням |
| **Неделя** | Дни листаются вбок без конца. «Время» — шкала часов с первого материала недели; совпадающие по времени — рядом, а если тесно — одной карточкой с «+N»; карточку можно перетащить на другой день и час. «Каналы» и «Площадки» — строками по дорожкам (только непустые, сворачиваются), на площадке — что там выходит |
| **План** | Список карточек месяца по дням и времени: «Демо · FULL» текстом, виден поставленный статус, остальные значки — при наведении; поиск по всему плану |
| **Банк тем** | Слева рубрики (Демо, Тезисы, Разборы…), справа — темы выбранной и «85 слотов ждут тему»: добавить списком, переставить, «в ближайший слот», «Разложить по слотам» — с датами и «Показать»; «Недавно разложены» — вернуть тему в банк |
| **Сетка** | Типовая неделя; рубрики и форматы строками для просмотра: дни точками и словами («каждый день», «кроме Сб», «через Ср»), время, площадки. Нажать на формат — панель правки: дни, время, площадки и что выходит на каждой (YouTube — FULL, Instagram — Reels), лимит, частота, слоты на период; блок «С каждым FULL» — тизер, анонсы, кросс-посты; каналы — цвет, дата старта, площадки |
| **Проверка** | Одно событие — одно нарушение: два FULL в день, сверх лимита, не свой день недели, канал ещё не запущен. У строки — действие: «Перенести «Landao» на Пн, 2 ноя» (ближайший свободный день по сетке) или «Оставить вне сетки» |

Карточка — тихая строка без рамки: сверху рубрика словом («Демо») и формат, время, ниже тема («Стратегия»);
в панели дня и в задаче — ещё и площадки строкой: «YouTube — FULL, Тизер · Shorts · Web — Анонс · Кабинет».
Одна карточка — материал целиком в своём канале: FULL с тизером и анонсами — одна карточка Dataist, анонс от Andre AIT
и кросс-посты — свои карточки. Полоска слева — цвет канала.

Как двигать и менять:
- **▶** на карточке, в строке плана или в «Сейчас» — статус «в работе» и задача по созданию контента: что сделать на каждой
  площадке (с галочками), когда выход и перенос на другую дату, к какому дню подготовить, кто делает, заметка.
- **Задача** — тема заголовком, под ней чек-лист по площадкам, ниже строкой «Пн, 26 окт · 12:00 · срок 23 окт · кто делает» (нажать — поменять), статус и «+ Заметка».
- **Статус** — значком: без значка — в плане, ▶ в работе, ⏸ на паузе, ✓ готово, ● вышло. На карточке — один значок в углу; все статусы — в задаче, форме и строке плана. Нажать тот же значок ещё раз — снова в плане.
- **Перетащить** карточку на другой день — в месяце, неделе или из панели дня; в неделе «Время» — ещё и на другой час.
  FULL едет вместе со своей группой (тизер, анонс в Кабинете, X, письма, Andre AIT); отключить можно в форме материала.
  Если на том дне уже есть FULL — в сообщении кнопка «Поменять местами».
- **Перейти к дате** — нажать на заголовок вида («Ноябрь 2026») и выбрать дату. Материал можно поставить и после конца плана — план продлится.
- **Тема** — только тема, без рубрики: «Стратегия», а не «Демо / Стратегия». У тизера, анонсов и писем группы тема та же, что у FULL.
- **Тему из банка** — перетащить из боковой панели на день: она займёт пустой слот этой рубрики или станет новым материалом.
- **Форма материала** — тема, дата и время, рубрика и формат; канал, площадки, статус, срок, кто делает и заметка — в «Подробнее».
- **Новый материал** («+» в шапке, «+» в неделе или двойной щелчок по шкале времени) по умолчанию создаётся с сопутствующими
  публикациями — по образцу ближайшего материала той же рубрики. Разовый материал на «чужой» день сразу «вне сетки» — проверка его не трогает.
- **⌘Z / Ctrl+Z** — отменить (и кнопкой в шапке), **⇧⌘Z / Ctrl+Y** — повторить (до 100 шагов). После каждого действия — кнопка «Отменить» во всплывашке.
- **Фильтры** — за кнопкой слева от заголовка: каналы, статус, «Ежедневные авто-публикации» (по умолчанию скрыты), «Только без темы», площадки, рубрики, банк тем.
  Включённые фильтры видны метками в шапке, ✕ снимает.
- **Как пользоваться** — значок «?» в рейле (на телефоне — в «Ещё»): все подсказки по экранам в одном месте.
- **Телефон** — внизу Сейчас, Календарь, План, Банк и «Ещё» (Неделя, Сетка, Проверка, Данные и тема, Как пользоваться); вид недели — в меню «Вид».

## Где хранится

План хранится **в браузере** (IndexedDB): правки переживают перезагрузку, но живут только в этом браузере.
Меню «⋯» внизу рейла:
- **Выгрузить JSON** — весь план с правками, чтобы перенести на другой компьютер или сохранить копию;
- **Загрузить JSON** — открыть такую выгрузку (проверяется формат, чужой файл план не испортит);
- **Календарь для таблицы (CSV)** — тот же формат, что `../out/4_calendar.csv` (можно открыть в Google Sheets);
- **Сбросить к исходному плану** — заново взять `public/seed.json` (отменяется кнопкой «Отменить»);
- **Тема** — светлая, тёмная или как в системе.

Исходный план `public/seed.json` пишет генератор: `python3 ../build.py`. Если генератор
перезапущен, а в браузере уже есть правки, новый план подхватится только через «Сбросить к исходному плану».

## Тесты

```bash
npm test             # логика и интерфейс (vitest + Testing Library)
npm run typecheck
npm run build && npm run preview &   # затем:
npm run test:e2e     # настоящий браузер: перенос мышью, банк тем, тёмная тема, телефон
```

`test:e2e` ищет Chromium в `/opt/pw-browsers`; другой путь — через переменную `CHROME`.
