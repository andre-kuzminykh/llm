# SMM · контент-план — приложение

Отдел **SMM** в Neuronium, и его первая часть — управление контент-планом: дашборд и календарь вместо таблиц,
банк идей и темы-хэштеги по каналам. Слева, как в Neuronium, — панель отделов: Менеджмент, HR, Маркетинг, SMM, Продажи,
Поддержка, Аналитика, Дизайн, Разработка, Инжиниринг (открыт SMM, остальные — «скоро»), сверху знак Nr, снизу профиль.
Стиль — дизайн-система Neuronium (Montserrat, один фиолетовый акцент, светлая и тёмная тема). Спецификация — [`SPEC.md`](SPEC.md).

## Запуск

```bash
cd content-plan/app
npm install
npm run dev        # http://localhost:5174
```

Собрать статический сайт (кладётся куда угодно: nginx, GitHub Pages, любой хостинг):

```bash
npm run build      # → dist/
npm run preview    # посмотреть сборку на http://localhost:5174
```

## Что умеет

| Экран | Что там |
|---|---|
| **Дашборд** | Сводка (просрочено, выходит за 7 дней, в работе, готово, слотов без темы); «Что делать» — на две недели вперёд: сверху «Просрочено», дальше по дням выхода, ▶ — начать задачу, фильтр статуса словами; «Банк идей» — хэштег кнопкой, темы списком, «Разложить по слотам», «Недавно разложены» с возвратом; «Темы» — хэштеги каждого канала и его разделов (Лаборатория, Академия, Кабинет): нажать — календарь только по этой теме, «Править» — переименовать или добавить; поиск темы по всему плану. Справа вверху — «Календарь» |
| **Календарь** | Виды — в шапке. «Время» (по умолчанию): неделя по часам, дни листаются вбок без конца, шкала — с первого материала недели; совпадающие по времени — рядом, а если тесно — одной карточкой с «+N»; лента Neuronium «24/7» — строкой над часами; карточку можно перетащить на другой день и час. «Каналы», «Площадки», «Темы» — дорожками (только непустые, сворачиваются). «Месяц» — в дне все единицы контента строками: время, #хэштег, тема; FULL — жирным, слот — пунктиром. Нажать на день — панель со всеми материалами дня. Справа вверху — «Дашборд» |
| **«+» справа внизу** | Новый контент: тема, дата и время, канал и раздел, хэштег, формат, площадки, статус, кто делает, срок, заметка; «Копии на другие даты»; «Пересоздать для площадок» — версии для YouTube, Instagram и других вместе с оригиналом (в той же карточке) или автоматически: когда оригинал отметят «Вышло», версии на следующий день становятся задачами «в работе» (⚡ на карточке) |

Карточка — тихая строка без рамки: сверху #хэштег и формат, время, ниже тема («Стратегия»);
в панели дня и в задаче — ещё и площадки строкой: «YouTube — FULL, Тизер · Shorts · Web — Анонс · Кабинет».
Одна карточка — материал целиком в своём канале: FULL с тизером и анонсами — одна карточка Dataist, анонс от Andre AIT
и кросс-посты — свои карточки. Полоска слева — цвет канала.

Как двигать и менять:
- **▶** на карточке или в «Что делать» — статус «в работе» и задача по созданию контента: что сделать на каждой
  площадке (с галочками), когда выход и перенос на другую дату, к какому дню подготовить, кто делает, заметка.
- **Задача** — тема заголовком, под ней чек-лист по площадкам, ниже строкой «Пн, 26 окт · 12:00 · срок 23 окт · кто делает» (нажать — поменять), статус и «+ Заметка».
- **Статус** — значком: без значка — в плане, ▶ в работе, ⏸ на паузе, ✓ готово, ● вышло. На карточке — один значок в углу; все статусы — в задаче и в форме. Нажать тот же значок ещё раз — снова в плане.
- **Перетащить** карточку на другой день — в месяце, неделе или из панели дня; в неделе «Время» — ещё и на другой час.
  FULL едет вместе со своей группой (тизер, анонс в Кабинете, X, письма, Andre AIT); отключить можно в форме материала.
  Если на том дне уже есть FULL — в сообщении кнопка «Поменять местами».
- **Перейти к дате** — нажать на заголовок календаря («Ноябрь 2026») и выбрать дату. Материал можно поставить и после конца плана — план продлится.
- **Тема** — только тема, без хэштега: «Стратегия», а не «Демо / Стратегия». У тизера, анонсов и писем группы тема та же, что у FULL.
- **Идею из банка** — перетащить из панели «Фильтры» в календаре на день: она займёт пустой слот этого хэштега или станет новым материалом.
- **Форма материала** — тема, дата и время, хэштег и формат; канал, площадки, статус, срок, кто делает, заметка, копии и версии — в «Подробнее».
- **Новый контент** («+» справа внизу, «+» в дорожке недели или двойной щелчок по шкале времени) по умолчанию создаётся с сопутствующими
  публикациями — по образцу ближайшего материала того же хэштега. Разовый материал на «чужой» день сразу «вне сетки».
- **⌘Z / Ctrl+Z** — отменить (и кнопкой в шапке), **⇧⌘Z / Ctrl+Y** — повторить (до 100 шагов). После каждого действия — кнопка «Отменить» во всплывашке.
- **Фильтры** — за кнопкой слева от заголовка: каналы и их разделы (у Dataist — Лаборатория, Академия, Кабинет), статус,
  «Ежедневные авто-публикации» (по умолчанию видны), «Только без темы», площадки, хэштеги, банк идей. Включённые фильтры видны метками в шапке, ✕ снимает.
- **Профиль** — внизу слева: «Как пользоваться» (все подсказки в одном месте), выгрузка и загрузка, тема оформления.
- **Телефон** — внизу Дашборд, Календарь и Профиль; «+» — справа внизу; вид календаря — в меню «Вид».

## Где хранится

План хранится **в браузере** (IndexedDB): правки переживают перезагрузку, но живут только в этом браузере.
Меню профиля внизу слева:
- **Выгрузить JSON** — весь план с правками, чтобы перенести на другой компьютер или сохранить копию;
- **Загрузить JSON** — открыть такую выгрузку (проверяется формат, чужой файл план не испортит);
- **Календарь для таблицы (CSV)** — тот же формат, что `../out/4_calendar.csv` (можно открыть в Google Sheets);
- **Сбросить к исходному плану** — заново взять `public/seed.json` (отменяется кнопкой «Отменить»);
- **Тема** — светлая, тёмная или как в системе.

Исходный план `public/seed.json` пишет генератор: `python3 ../build.py`. Если генератор
перезапущен, а в браузере уже есть правки, новый план подхватится только через «Сбросить к исходному плану».

## Тесты

```bash
npm test             # логика и интерфейс (vitest + Testing Library)
npm run typecheck
npm run build && npm run preview &   # затем:
npm run test:e2e     # настоящий браузер: перенос мышью, банк тем, тёмная тема, телефон
```
