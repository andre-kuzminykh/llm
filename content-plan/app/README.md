# Контент-план — приложение

Календарь контент-плана вместо таблиц: смотреть, двигать, создавать и править материалы,
вести банк тем и сетку рубрик. Стиль — дизайн-система Neuronium (Montserrat, фиолетовый и
оранжевый акценты, светлая и тёмная тема). Спецификация — [`SPEC.md`](SPEC.md).

## Запуск

```bash
cd content-plan/app
npm install
npm run dev        # http://localhost:5174
```

Собрать статический сайт (кладётся куда угодно: nginx, GitHub Pages, любой хостинг):

```bash
npm run build      # → dist/
npm run preview    # посмотреть сборку на http://localhost:5174
```

## Что умеет

| Раздел | Что там |
|---|---|
| **Календарь** | Месяц: FULL дня, сколько публикаций по каналам, «N без темы», красная точка — нарушение, суббота подписана «отдых». Нажать на день — панель со всеми материалами дня |
| **Неделя** | Дорожки по каналам (у Dataist — FULL, Shorts, Lab, Academy, Office, тексты) или по площадкам, как в исходной таблице. «+» в ячейке — новый материал |
| **План** | Список материалов месяца по дням, смена статуса прямо в строке, поиск по всему плану |
| **Банк тем** | Темы без даты по рубрикам: добавить списком, переставить, «в ближайший слот», «Разложить по слотам» |
| **Сетка** | Рубрики: дни недели, площадки, лимит в день, частота, «Слоты…» на период; типовая неделя из сетки; каналы — цвет, дата старта, площадки; новые рубрики и каналы |
| **Проверка** | Все нарушения: два FULL в день, сверх лимита, не свой день недели, канал ещё не запущен — с переходом к дню |

Как двигать и менять:
- **Перетащить** карточку на другой день — в месяце, неделе или из панели дня. FULL едет вместе со своей группой
  (тизер, анонс в Кабинете, X, письма, Andre AIT); отключить можно в форме материала.
- **Тему из банка** — перетащить из боковой панели на день: она займёт слот «…» этой рубрики или станет новым материалом.
- **Правка заголовка FULL** пересобирает заголовки группы: «Демо / Агент продаж» → «Тизер: Демо / Агент продаж», «Анонс / Агент продаж».
- **Новый материал** («Материал» в шапке или «+» в неделе) по умолчанию создаётся с сопутствующими публикациями — по образцу ближайшего материала той же рубрики.
- **⌘Z / Ctrl+Z** — отменить, **⇧⌘Z / Ctrl+Y** — повторить (до 100 шагов). После каждого действия — кнопка «Отменить» во всплывашке.
- Фильтры слева: каналы, площадки, «Ежедневные авто-рубрики» (по умолчанию скрыты, чтобы видеть главное), «Только без темы».

## Где хранится

План хранится **в браузере** (IndexedDB): правки переживают перезагрузку, но живут только в этом браузере.
Меню «⋯» внизу рейла:
- **Выгрузить JSON** — весь план с правками, чтобы перенести на другой компьютер или сохранить копию;
- **Загрузить JSON** — открыть такую выгрузку (проверяется формат, чужой файл план не испортит);
- **CSV-календарь** — тот же формат, что `../out/4_calendar.csv` (можно открыть в Google Sheets);
- **Сбросить к исходному плану** — заново взять `public/seed.json` (отменяется кнопкой «Отменить»);
- **Тема** — светлая, тёмная или как в системе.

Исходный план `public/seed.json` пишет генератор: `python3 ../build.py`. Если генератор
перезапущен, а в браузере уже есть правки, новый план подхватится только через «Сбросить к исходному плану».

## Тесты

```bash
npm test             # логика и интерфейс (vitest + Testing Library)
npm run typecheck
npm run build && npm run preview &   # затем:
npm run test:e2e     # настоящий браузер: перенос мышью, банк тем, тёмная тема, телефон
```

`test:e2e` ищет Chromium в `/opt/pw-browsers`; другой путь — через переменную `CHROME`.
